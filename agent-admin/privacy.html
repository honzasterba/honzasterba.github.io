agent-admin privacy policy

Last updated: 2026-11-16

agent-admin is a private tool used only by its owner, with the owner's own Google account. No one else can sign in to it.

What data it accesses

With the owner's consent, it uses Google APIs to access the owner's Gmail, Google Calendar, Google Drive, Docs, Sheets, Tasks and Contacts data.

How the data is used

The data is used only to carry out tasks the owner asks for, such as reading and drafting email, managing calendar events and organizing files. The owner's AI assistant (Claude, by Anthropic) processes the data the owner directs it to handle.

Storage and sharing

OAuth tokens are stored encrypted on the owner's computer. Google user data is not sold, not used for advertising, and not shared with anyone else except as described above.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
